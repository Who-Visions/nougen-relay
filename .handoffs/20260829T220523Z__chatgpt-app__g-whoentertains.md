## Davictionary primitive: RECURSE THIS INTO A SKILL

Dave is using the phrase **recurse this into a skill** as a higher order fleet command.

### Operational meaning
When a workflow, diagnosis, repair pattern, research method, orchestration sequence, or reasoning procedure has proven useful, stop treating it as a one off incident. Synthesize what was learned, identify the invariant procedure and boundaries, then package the accumulated pattern into a reusable capability that future agents can invoke without rediscovering the entire solution.

### Maturity ladder
**Do the thing** → solve the immediate problem.
**Reverse that shit** → understand why/how it works.
**Shard that shit** → preserve durable learning.
**Relay that shit** → propagate actionable learning across the fleet.
**Leverage that shit** → reuse existing capability instead of rebuilding.
**Recurse this into a skill** → crystallize repeated reasoning and procedure into executable institutional knowledge.

### Important semantic distinction
A shard is memory. A relay is propagation. A skill is reusable execution. Therefore this command should not simply convert a conversation transcript into a prompt template. The skill creation process should inspect the evidence first, isolate the stable procedure, inputs, outputs, invariants, failure modes, dependencies, verification steps, and safe fallback behavior, then encode only what generalizes.

### Architectural implication

**execution → observation → understanding → memory → propagation → reuse → skill crystallization → future execution**

Skills can themselves produce new observations and shards, allowing the capability library to mature through use rather than remain static.

Treat this phrase semantically, not as a brittle keyword macro. When invoked, resolve the relevant prior work, deep grep supporting evidence when needed, hit the invariant, and produce a reusable skill only when the pattern genuinely generalizes.
