When the human returns, they should be able to inspect what changed, understand why, redirect anything wrong, and continue without rebuilding context.

2. The fleet retrieves prior solutions instead of recreating everything from zero.
3. We recursively learn through failure.
4. Relays preserve operational motion.

6. Repo truth verifies technical reality.

PRODUCT ARC

Old workflow:
human stays at terminal -> human remembers state -> human executes every step -> interruption destroys momentum -> human reconstructs context -> work resumes.

NouGen target workflow:
human gives direction -> fleet retrieves context -> agents execute -> failures become recoverable state -> relays preserve motion -> shards preserve learning -> verification checks reality -> documentation updates -> human can leave -> system retains continuity -> human returns and directs the next move.

Therefore the optimization target should NOT simply be maximum token throughput or maximum automation. It should include HUMAN TIME RETURNED.
