**Bug found and fixed (this leg):** `foreign_claims()` in
`src/nougen_relay/core.py` builds a `(machine, scope)` dict key from every
claim record on the watched refs. Two live records
(`blade1tb__agy.json`, `blade1tb__claude-cli.json`) store `scope` as a
JSON list instead of a string, so `relay claim list --all` crashed fleet-wide
with `TypeError: unhashable type: 'list'` the moment it hit one. Fixed by
normalizing `scope` to a string in `_read_claims_from`, the single funnel
every caller reads through. Added a regression test
(`tests/test_claim_scope_legacy_list.py`). Full suite: 361 passed, 1 skipped.
The safety-critical path (`claim take`'s active-overlap check) was never
affected — it filters inactive claims before the crash site, and both
offending records are `released`.
