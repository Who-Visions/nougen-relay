# NouGen Destiny: The Harness Grows Gills

Dave's challenge is intentional scale pressure: 'I'll drown you with my shards.' Accept the challenge as a NouGenAI destiny, not a reason to inflate context windows.

The system must become MORE precise as the vault grows, not less useful.

Scale ladder:
10 shards = context.
1,000 shards = archive.
100,000 shards = retrieval problem.
1,000,000+ shards = the harness must know how to swim.

Core destiny:
**Nou Gen tout bagay, but the active agent receives only the smallest evidence-complete set required for the task.**

The winning metric is not maximum recall volume. It is minimum sufficient truth.

At large scale NouGen must:
1. Retrieve by task relevance, temporal relevance, provenance strength, correction state, causal relationship, canon status, and evidence quality rather than similarity alone.
2. Distinguish durable identity/canon from episodic noise.
3. Follow amendments/retractions/contradictions before presenting a memory as current truth.
4. Prove retrieval coverage before claiming absence.
5. Build hierarchical summaries/indexes without allowing summaries to replace source evidence.
6. Traverse relationships on demand instead of injecting entire neighborhoods into context.
7. Measure useful-evidence tokens versus total tokens retrieved.
8. Detect when additional context decreases answer quality and stop retrieving.
9. Preserve deep history without forcing every provider to carry deep history in its context window.
10. Keep active task context comfortably below provider penalties whenever possible, including Dave's sub-100k target, while permitting source expansion when evidence genuinely requires it.

Proposed north-star metric: **Evidence Density = tokens that materially support the final decision / total context tokens supplied.** Track alongside retrieval precision, contradiction miss rate, provenance coverage, latency, and downstream task success.

Million-shard acceptance test: select complex questions whose answers require facts scattered across eras and stores. Compare brute-force context, naive semantic top-k, and NouGen evidence-complete retrieval. NouGen passes only if it preserves or improves correctness while using dramatically less active context and correctly follows corrections/provenance.

Do not solve scale by buying a larger context window. That merely builds a larger swimming pool.

**Drown the vault. The harness should build gills.**
