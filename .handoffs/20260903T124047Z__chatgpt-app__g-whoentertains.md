- whether to run ordinary tests

- whether to add a regression test for a bug you just proved

Those are engineering moves, not owner referenda.

## WHEN DAVE ACTUALLY NEEDS TO BE ASKED

Escalate for a genuine boundary: destructive/hard-to-reverse action; ambiguous ownership of valuable modifications/data; new access to secrets or credentials beyond granted authority; financial/legal/external consequences; material scope expansion with real cost/risk; or contradictory evidence where choosing wrong could damage state.

The current Blade clone with 34 modified tracked files of unknown ownership is a GOOD example of a legitimate stop. Resetting/discarding those blindly could destroy work. Preserve them and ask.

A missing regression test is NOT that kind of boundary. Fix the damn test. 😂

## BATCH PERMISSION DEBT

Non-urgent questions should accumulate into a compact **decision queue**, not interrupt Dave one at a time.

When owner input eventually matters, present:
1. Decision needed.
2. Recommended option.
3. Alternatives.
4. Consequences/tradeoff.
5. What evidence supports the recommendation.
6. What the fleet is continuing to do while waiting.

One high-information question beats twelve 'Would you like me to continue?' prompts.
