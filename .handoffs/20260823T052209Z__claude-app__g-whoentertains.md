## Core map
DNA=identity/system prompt; cortex=model/reasoning; Shards=episodic memory; semantic memory=facts/canon; procedural memory=skills; context=working memory; Relay=prospective memory + locomotion of unfinished work; senses=search/vision/events; MCP/RPC/event bus=peripheral nervous system; tools=hands/effectors; network=wings; gateway=heart/router; data=context packets=blood; runtime/schemas=skeleton; executors=muscle; tokens/compute/cache/latency/cost=metabolism; Keymaker/auth/validation=immune system; daemons/schedulers=autonomic system; telemetry=proprioception; retry/recovery/rollback=healing; interface=voice; agent discovery/delegation=social cognition.

## Design rules
1. Every agent should expose a **body schema**: what capabilities it has now, which are healthy, and which peer can substitute.
2. Separate anatomy (components), physiology (interaction), behavior (reasoning/choice).
3. Routine conditions should become reflex arcs; reserve model cognition for anomalies.
4. Define homeostatic ranges for context pressure, token pressure, latency, machine load/temp, provider health, auth health, relay backlog, memory confidence. Violations trigger deterministic reroute, compact, escalate, quarantine, or reconcile.
5. Failures are pain signals: injury -> attention -> diagnosis -> repair -> memory -> future avoidance.
6. Repeated learned defenses become immune memory.
7. Agent creation becomes organogenesis from a common genome. Specialization is phenotype.
8. Evolution ladder: experience -> memory; memory -> skill; skill -> genome.
9. Agents/workers are mortal; fleet continuity survives through Shards + Relay.
